## 3. 技术方案

- **环境约束**:Windows,无 Blender;`python` 仅为 Windows Store 占位符(exit 49),安装运行时有写入工作区外之嫌 → 放弃;Node v26 可用 → **纯 Node.js 零依赖实现全部管线**(自带 PNG/VOX 编码,仅用 `zlib`)。
- **生成器**:`buildTerrain`(fbm 噪声盆地 + 山脊)→ `buildWater`(溪/渠/塘雕刻)→ `buildTerraces`(3 级量化 + 坡度门槛)→ `buildRoads`(折线平整 + 石面)→ `voxelizeTerrain` → 参数化建造器(`buildTulou/buildHouse/buildAncestralHall/...`,距离场划分环带:外墙 3 厚 → 房间环 → 木走廊 → 天井)→ 农业/植被/道具/村民 → 导出。
- **渲染器**:正交等轴 **DDA 光线投射**(逐像素,非 mesh 栅格化):
  - 列高度图跳步加速(跳步前沿射线路径逐列校验防穿透);
  - 日照阴影 = 逐体素日方向 DDA + 计数排序降序处理 + memo 化传播,3 次切向采样软化;
  - 角点占据式 AO、半球天光环境光、夯土层理/风化/青苔与缺瓦等程序化材质变化;
  - 2× SSAA、Reinhard + S 曲线、轻雾与暗角;单视图 5–20s(纯 CPU)。

## 4. 迭代过程与踩坑记录(过程核心)

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 首 render 建筑悬浮、地形缺失 | `voxelizeTerrain()` 忘记调用 | 补调用,并让 `flatten*` 平整时同步重铺地形列 |
| 2 | 土楼屋顶看起来"破损",内院穿帮 | 渲染器高度图跳步只检查落点列,视线**穿透**近侧屋顶/墙体 | 跳步前沿射线逐列校验 `hTop > 射线z` 则放弃跳步 |
| 3 | 全图发灰发白 | 调色板按 sRGB 取值却又做线性→gamma,二次提亮 | 去掉末端 gamma,改 Reinhard + S 曲线直出 |
| 4 | 方形土楼楼板/栏杆消失 | `floorH=2.6` 非整数,`setV` 浮点索引静默失败 | `slabZ = Math.round(...)`;楼高改整数 |
| 5 | 屋顶内环低于顶层楼板,楼板穿顶 | `zRI = wallTop − fh + 1` 几何推导错误 | 内檐 ≥ 顶层楼板 +2,外檐 +4,阶梯环闭合 |
| 6 | 南部稻田"消失" | 田面高程写死 7.x,而周边地形 11–16,被自己挖的坑壁遮挡 | 村前/溪东谷地压平缓坡带,田面高程贴合地形 |
| 7 | 东侧基座出现裂口 artifact | 谷地压平公式无淡出,削平了山缘 | `x>140` 后按 0.38/格快速淡出 |
| 8 | **(用户指出)** 坡屋顶镂空 | `buildGableRoof` 每层只画檐口轮廓线,未填坡面 | 每层整带实心填充 + 顶部正脊;祠堂歇山顶/祖堂小殿同修;祠堂正脊跨度按新顶宽修正 |
| 9 | **(用户指出)** 三座楼只看到两座 | 环兴楼贴主视图左缘且被树林竹林半包 | 取景左移放宽(74,76 / 半宽 80);楼周 26 格禁植林;竹林退远 |
| 10 | viewer.html 全空只显示天空色 | `OrthographicCamera(-1,1,1,-1,1200)` 5 参构造 → `near=1200` 全场被近平面裁掉 | 显式 `near=1, far=1600` |
| 11 | 次要调优 | 林树入侵村落、水田灰白、内院过暗、白花过密、E 侧裸土疤痕 | rim 门槛 0.80、水色加深、环境光/AO 调平衡、裸土限制村落核心区 |

共 7 轮完整重建渲染 + 3 次诊断性调试(水平切片、径向材质探针、无光照材质视图)。
