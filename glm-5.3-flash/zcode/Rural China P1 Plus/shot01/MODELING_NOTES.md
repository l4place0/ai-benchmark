## 2. 体素建模逻辑(Voxel Construction Language)

全部几何体由 **离散体素堆叠** 构成,无任何平滑曲面/网格变形:

- **圆形土楼**由逐格距离场 `d = hypot(x−cx, y−cy)` 划分环带:外墙(3 体素厚)→ 房间环(进深 4)→ 木走廊(宽 2)→ 中央天井;加低频噪声抖动(±0.9)使墙体轮廓手工感、不完全规则。
- **方形土楼**使用归一化方环距离 `max(|dx|/hw, |dy|/hh)`,环带逻辑与圆楼一致,屋顶为逐层收缩的方环(攒耳式阶梯)。
- **屋顶**全部为阶梯体素:环形屋顶外高内低(4 级落差),民居双坡悬山屋顶逐层内收 + 山墙填充 + 檐口封板,祠堂为带正脊与鸱吻起翘的歇山变体。
- **夯土墙**:基色 + 水平层理带(夯筑分层)+ 低频风化斑 + 底部青苔,三种墙材区分建筑年代。
- **小物件**(水井、石磨、水缸、扁担箩筐、晒谷架等)以 1–4 体素的小尺度堆叠表达,与建筑保持同一比例语言。
- 允许少量程序噪声造成的"人工误差"(屋顶缺瓦、墙体凹凸、路面边缘不规则),避免复制粘贴感。

### 参数化建造函数(可复用)

```js
buildTulou({ cx, cy, r, ry, wallT, floors, floorH, z, wallMat, gateDir, age, shape, courtyard })
buildHouse({ x, y, w, d, fl, facing, wallMat, wins })      // 客家民居
buildAncestralHall(cx, cy)                                  // 祠堂
buildVillageGate(cx, cy, axis)                              // 村口门楼
buildTree(cx, cy, kind, scale)                              // kind: broadleaf / pine / fruit / banyan
buildBamboo(cx, cy, r, density)                             // 竹林
buildPaddy(x0,y0,x1,y1,level) / buildGarden / buildTea      // 农业
buildWell / buildStoneTable / buildJar / buildFirewood / buildDryingRack / buildStoneMill / buildFence / buildBridge ...
buildVillager(cx, cy, pose, dir)                            // pose: walk / carry / field / sit
```

三座土楼与十三栋民居均由同一组函数以**不同参数**生成,再以年代(墙材)、朝向、层数、周边环境产生差异,而非复制摆放。

## 4. 村落布局逻辑(空间组织)

场景 170×150×54 体素。布局遵循「山地 → 村落 → 道路 → 建筑群 → 土楼 → 天井」的层级,顺应地形而非网格排布:

```
        北: 主山体 · 松杉林 · 梯田(稻田)
            ┃ 泉塘 → 溪流(自北向南)
  环兴楼(台地)          东坡茶园
   竹林  ┃ 石阶路          ┃ 石桥
C组民居 — 次路 — 主路 — 溪东稻田 · 果园
祠堂 · 前坪 — 广场(井/晒架/石桌) — 溪流
   主路(村口门楼)      振昌楼(核心圆楼, 门朝广场)
E组民居 · 磨坊      B组民居 — 菜园
        南部稻田带(x2 条田埂路)      D组民居 · 谷仓 · 鸡舍
                              庆成楼(方楼, 门朝路)
```

- **主路**(宽 3–4):村口门楼 → 广场 → 绕主楼西侧 → 石阶上台地至环兴楼;向东过石桥接方楼与田带。
- **次路**(宽 2–3):连接民居群、菜园、祠堂前坪、溪东田带。
- **小路**(宽 1–2):田埂路、楼间巷道,通往井台与林缘。
- **公共空间**:广场(石板铺地、水井、石桌凳、晒谷架与谷垫、灯笼柱)+ 祠堂前石坪;核心土楼天井为半公共内院。
- **村口**:木柱灰瓦门楼横跨主路,挂红灯笼一对,侧立石碑,前后有竹林与大树——整个场景的空间起点。
- **建筑群**:13 栋客家民居(1–2 层,朝向 4 向变化,含悬山/一层囤顶式灰瓦、木栏小阳台)+ 祠堂 + 谷仓 + 磨坊 + 鸡舍;以 3–5 户为一组沿路成团,间距、朝向、高差各不相同。

## 5. 地形参数

- 盆地中心 (88,64),基础高度 9;`rim = max(|dx|/78, |dy|/62)` 的 1.6 次幂 × 12.5 形成山间盆地轮廓;北缘另加线性抬升形成主山体(峰值限高 30)。
- 3–4 阶 value-noise fbm 叠加(fbm 振幅 3.0 + rim×4.5),山区起伏、谷底平缓。
- **村前田园带**(y<34)与**溪东田谷**(x>112)以缓坡公式压平,衔接村落(≈9)与边缘(≈10.5–12)。
- **梯田**:北坡与东坡按「高度 3 级量化 + 80% 混合 + 噪声边界 + 坡度门槛(局部高差≥2.2 才成梯)」生成,不完全规则;田面布稻苗、部分灌水。
- **溪流**:泉塘(源头,半径 7)→ 折线河道(宽 4–5,深度 2)自北向南穿村东侧,落差处布白色急滩泡沫;出村口处切开基座,侧壁可见水体剖面。
- **灌溉渠**:自溪流西岸沿等高线引向南部稻田(石砌,宽 2),途中有跌水泡沫,末端接小水塘。
- **基座**:整块 diorama 直切底座,侧壁显示夯土/砂砾/岩层分层带,顶缘草皮收边。

---

## 6. 水系流向

**山泉(泉塘)→ 溪流 → 石桥 → 灌溉渠 → 水塘 → 南部稻田/溪东稻田**,有来源、有去向;渠水体高程沿程递减(19.5 → 8.4),跌水处以泡沫体素标记,无切穿建筑的水体。

## 7. 植被系统(三层群落)

- **近景**:庭院/路缘散石、草茎、野花、灌木、竹丛(村口、楼后、溪畔共 3–4 片,竹竿分节、高度 6–10 随机)。
- **中景**:阔叶树(2–3 色树冠抖动)、果树(橙/红果点)、榕树(广场东南、村口,2×2 干 + 宽冠)、松树(圆锥层叠)。
- **远景**:山脊密林(松 60% / 阔 40%,按噪声密度成片分布)、梯田田面稻作、茶园(东坡等高线列植)。
- 村落核心区(rim<0.80)不密植,保留聚落开敞感;全部植物为体素构造,无平滑面。

## 12. 光照参数

- **日光**:方位 225°(西南斜射)、高度 44°,暖白 (1.06, 0.97, 0.82),对应上午侧光;阴影为逐体素日光照度场(DDA 沿日向步进 + 记忆化)+ 3 次切向采样软化边缘。
- **天光**:半球环境(天顶冷蓝 0.52,0.60,0.68 / 地平暖灰 0.72,0.72,0.68),顶面 0.74、侧面向日 0.58→背日 0.54、底面暖反弹。
- **AO**:角点占据式体素 AO(4 角 × 侧/角邻居采样,权重 0.24)。
- **氛围**:距离空气透视(极轻,≤0.16)、暗角、Reinhard 高光压缩、S 曲线对比。
- 点缀:土楼院内少量暖光窗、村口与祠堂红灯笼(自发光材质,弱)。

## 13. 性能

- 总体素 475,180(地形 89.6% / 植被 6.0% / 建筑 3.8% / 水 0.6%);渲染仅对**暴露体素**做光线投射,配合列高度图跳步(逐列遮挡校验防穿透)与 memo 化阴影场,单视图 5–20 秒(纯 CPU,2× SSAA)。
- viewer.html 使用单 InstancedMesh(10 万暴露体素实例)+ 共享材质 + 2048 阴影贴图,普通设备可实时交互。
- 远景树林与远景建筑保持低细节体块,符合 LOD 思路。
