# 线之屋 · The Line Room

一件纯浏览器单机的互动艺术作品：一间可以探索和操作的矢量线稿风格房间。
白纸为底、墨线为形——所有家具与建筑均由程序化几何实时投影绘制，无任何图片、贴图或外部资源。

## 启动方式

- **直接打开**：双击 `index.html` 即可运行（经典脚本，file:// 协议可用）。
- **本地服务器**（可选）：`node _dev/serve.js` → http://127.0.0.1:8143

断网环境完全可运行；页面不发出任何网络请求。

## 操作

| 操作 | 效果 |
|---|---|
| 拖动 | 环绕视角（带阻尼与限位） |
| 滚轮 | 推近拉远 |
| 右键 / Shift 拖动 | 平移视点 |
| 点击物件 | 与之互动 |
| H | 标记所有可互动之物 |
| L | 拨动电灯开关（昼↔夜） |
| M | 静音 |

## 可互动之物（20 处）

门（开合·门轴吱呀）· 窗帘（开合·布料声）· 电灯开关（昼↔夜全局变化）· 台灯（开关·光晕·局部照明）·
茶杯（蒸汽常动·点击迸发）· 椅子（拉出推回）· 书桌抽屉（滑开·内含铅笔橡皮）· 书架（六本书可抽插）·
红皮书（抽出露出暗格——一件小秘密）· 挂钟（真实走时·每秒滴答）· 挂画 ×2（扶正 / 换画）·
吊扇（三档·惯性启停）· 风铃（摆动·风来自周期阵风）· 绿植（簌簌发抖）· 地球仪（拨动自转·23.5° 倾角）·
边柜（双门+抽屉）· 唱片机（落臂·唱片旋转·生成式五声音阶音乐+炒豆声）· 抱枕 ×2（按压回弹）·
茶几上的书（翻开合上）· 地毯（掀起一角）。

持续的生命感：时钟走针、蒸汽、云影漂移、窗外昼夜、阵风拂动帘幕/风铃/绿植、悬浮尘埃、
唱片旋转、吊扇惯性——以及一整层 Web Audio 合成的环境声（鸟鸣/蟋蟀/微风/哼鸣），随昼夜淡入淡出。

## 技术栈

原生 HTML/CSS/JavaScript，Canvas 2D。自研微型 3D 管线：透视投影、画家算法遮挡、
面级明暗（方向光+台灯点光）与阴影排线（hatching）、部件级变换（铰链/滑轨/自转）、
基于部件 OBB 的射线拾取。音频全部由 Web Audio API 实时合成（无音频文件）。

代码结构：`js/engine.js`（渲染/相机/拾取/补间）· `js/builders.js`（几何构建）· `js/audio.js`（合成音效）
· `js/room.js`（建筑+窗外景）· `js/objects/*.js`（每件家具一个文件）· `CONTRACT.md`（开发契约）。
