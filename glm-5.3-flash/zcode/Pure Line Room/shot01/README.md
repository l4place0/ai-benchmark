# 纯线之室 · Pure Line Room

一间可以用鼠标住进去的"矢量线稿房间"——白纸般的空间里，家具全部由黑色线条构成，
每件物件都可以被发现、悬停、点击，并给出属于自己的行为反馈。

![类型](https://img.shields.io/badge/%E7%B1%BB%E5%9E%8B-%E7%BA%AF%E5%89%8D%E7%AB%AF%E4%BA%92%E5%8A%A8%E4%BD%9C%E5%93%81-informational)
（无任何运行时网络请求；断网可玩）

## 启动方式

**方式一（推荐）**：直接双击 `index.html` —— 无构建、无依赖、无网络请求，现代浏览器（Chrome / Edge / Firefox）打开即玩。

**方式二**：本地静态服务（可选）：

```bash
node server.mjs 8642     # 纯 node 标准库实现，无第三方包
# 打开 http://127.0.0.1:8642/
```

## 玩法

- **拖动** 环视房间 · **滚轮** 缩放 · **右键拖动** 平移 · **双击空白** 复位视角
- **点击**房间里的东西：门、窗、窗帘、电灯开关、吊灯、台灯、杯子、椅子、书架上的三本书、
  五斗柜（两只抽屉＋柜门）、唱片机、地球仪、沙发、两只抱枕、茶几、盆栽、地毯、
  挂钟、装饰画、风铃、吊扇、书桌 —— 共 **23 个**可发现互动（右下角计数）
- 有的物件自己就会动：挂钟走真实时间、杯中有热气、风铃常摆、窗帘布起伏、
  吊扇惯性旋转、盆栽叶颤、唱片旋转、昼间窗台有光束与浮尘
- 点击**窗户**切换昼夜；点击**电灯开关或吊灯**开关灯 —— 夜里关灯，整个房间会换成
  "暗底亮线"的反相画法，只剩台灯的一圈暖光
- 所有音效由 Web Audio API 现场合成（开关声、抽屉、门轴吱呀、风铃、钟摆 tick、
  吊扇嗡鸣、黑胶唱片的炒豆声与旋律……），无任何音频文件

## 技术栈

纯 HTML / CSS / JavaScript（ES2019 普通脚本，零依赖、零构建）：

- 自研 2.5D 线稿渲染引擎 `js/engine.js`：透视投影、近平面裁剪、画家算法排序、
  纸面填充遮挡、深度感知线宽、逐帧拾取、补间/弹簧、粒子与光晕、昼夜配色系统
- 音频引擎 `js/audio.js`：Web Audio 全合成（振荡器 + 噪声 + 滤波 + 包络）
- 物件模块 `js/objects_*.js`：建筑构件 / 墙顶装饰 / 书房 / 起居四组约 1450 个矢量部件
- 装配与界面 `js/main.js`：场景装配、HUD、悬停名牌、发现计数（localStorage 持久化）

## 文件结构

```
index.html          入口（双击打开）
css/style.css       纸与墨的界面样式
js/engine.js        渲染内核（投影/排序/遮挡/拾取/补间/粒子/昼夜）
js/audio.js         Web Audio 合成音效
js/objects_arch.js  建筑构件：壳体/门/窗/窗帘/电灯开关
js/objects_deco.js  墙顶装饰：挂钟/装饰画/风铃/吊扇/吊灯
js/objects_study.js 书房：书桌/椅/台灯/杯子/书架与书
js/objects_lounge.js 起居：五斗柜/唱片机/地球仪/沙发/抱枕/茶几/盆栽/地毯
js/main.js          装配 + HUD + 发现机制
SPEC.md             模块契约与对象行为规格（开发文档）
server.mjs          可选的本地静态服务（仅开发用）
test_engine.js / test_integration.js   无头自测（node test_engine.js）
```

## 断网与离线

运行时不发起任何网络请求：无 CDN、无外部字体、无图片、无音频文件、无统计脚本。
断网状态下双击 `index.html` 即可完整体验（首次交互后音频自动解锁）。
