# 纯线房间 · Pure Line Room

一间完全用矢量线条"画"出来的互动房间。白色纸面、黑色墨线、
可以旋转的视角、会动的家具，以及昼夜交替的光线与声音。

纯浏览器单机作品：零依赖、零构建、断网可运行。

## 启动方式

- **直接双击打开 `index.html`**（file:// 协议即可完整运行），或
- 任意静态服务器，例如：`python -m http.server` / `node` 静态服务，
  然后访问对应地址。

首次进入后点击任意处开始（同时解锁声音）。

## 操作

| 操作 | 效果 |
|---|---|
| 拖动空白处 | 旋转视角 |
| 滚轮 / 双指 | 缩放 |
| 双击空白 | 复位镜头 |
| 悬停物件 | 高亮 + 提示牌 |
| 点击 / 按住物件 | 与物件互动 |

右上角小按钮为总静音开关。

## 房间里的可交互物件（28 处）

- **门** — 开合（铰链动画 + 吱呀声）
- **窗户** — 开窗（风会进来：窗帘、风铃、绿植、蒸汽都会响应）
- **窗帘** — 拉合 / 拉开（褶皱随收拢压缩）
- **电灯开关** — 切换昼 / 夜（全局光线、窗外天色、环境音整体响应）
- **台灯** — 开关（夜间可见暖光晕染）
- **茶杯** — 蒸汽开 / 关（持续蒸汽动画）
- **地球仪** — 点击旋转（惯性减速）
- **抽屉（桌 / 柜）×3** — 拉开 / 推回
- **柜门 ×2** — 开合
- **书 ×4** — 从书架抽出 / 推回
- **挂钟** — 真实时间 + 机械跳秒 + 报时
- **装饰画** — 摆正 / 翻页换画（3 幅）
- **沙发** — 按压回弹
- **抱枕 ×2** — 抛起翻滚落地
- **茶几 / 椅子** — 按住拖动
- **地毯** — 切换三种花纹
- **唱片机** — 播放 / 停止（唱臂落盘、唱片旋转、黑胶音乐）
- **吊扇** — 开关（惯性启停，风力影响风铃）
- **风铃** — 点击与风力触发管音

窗外还有随真实时刻移动的太阳、白天的云、夜晚的残月与闪烁星群。

## 技术

- 自研微型 3D 线稿引擎（Canvas 2D）：场景图 → 透视投影 → 画家算法 +
  背面剔除 + 近平面裁剪 → "纸色填充遮挡 + 轮廓/边界/内部三级墨线"，
  辅以附着细节线、排线与动态地面阴影，得到隐藏线渲染（HLR）的制图质感。
- 全部几何为程序化生成（盒 / 圆柱 / 球 / 多边形 / 细节线 / 排线）。
- 音频全部由 Web Audio API 运行时合成：17 种一次性音效 +
  吊扇 / 黑胶（生成式 lo-fi）+ 昼夜环境底噪 + 秒针滴答四个持续层，
  带简易反馈延迟"房间感"，无任何音频文件。
- 昼夜为全局主题插值：纸色、墨色、窗外天色、灯光暖色、环境音同步过渡。
- 无网络请求、无外部字体 / 图片 / 音频 / CDN；`file://` 直接可用。

## 文件结构

```
index.html          入口
css/style.css       HUD 样式
js/math3d.js        向量 / 矩阵
js/engine.js        渲染引擎 / 场景图 / 拾取 / 相机 / 主题 / 环境
js/audio.js         Web Audio 合成器
js/main.js          建筑（地板 / 墙 / 天花）与启动
js/objects/*.js     20 个物件模块（每个文件一个 IIFE，注册到全局 PLR）
API.md              模块协作契约（开发文档）
```

（index.html 顶部的小错误捕获脚本仅用于自动化测试读取页面错误，不影响运行。）
