# 桜町駅 · Sakura Station — 三渲二樱花车站（Three.js）

一个用 Three.js（r170）从零程序化搭建的日系三渲二（toon/cel shading）樱花车站场景：
春日午后四点的小镇、商店街、站前广场、站台与停靠中的樱花色通勤电车、铁路道口，
配合约 1200 片缓慢飘落旋转的樱花花瓣与树冠透光，适合自由第一人称漫游。

## 运行

场景使用 ES Modules，需要通过本地 HTTP 服务器打开（任意一款均可）：

```bash
# 方式一：内置的 Node 静态服务器
node serve.mjs 8177
# 然后浏览器打开 http://localhost:8177/

# 方式二：Python（如果可用）
python -m http.server 8177
```

three.js 已本地化在 `js/lib/three.module.js`，无需外网。

## 操作

| 输入 | 功能 |
| --- | --- |
| 点击画面 | 锁定鼠标，进入第一人称漫步 |
| `W A S D` | 移动（`Shift` 疾走） |
| 鼠标 | 环视（未锁定时也可按住拖动） |
| `1` – `5` | 预设机位：街道正面 / 站台 / 铁路道口 / 广场樱花 / 电车正面 |
| `Esc` | 释放鼠标 |

URL 参数：`?view=N` 直接跳到机位 N；`&ui=0` 隐藏界面文字（截图用）。

## 场景里有什么

- **车站**：站房（站名牌 / 路线图 / 运賃表 / 海报 / 时钟）、开放门廊与检票闸机、
  自动售票机、站台（黄色点字引导砖、白色安全线、候车标线）、雨棚与荧光灯、
  悬挂式站名牌 / 方向牌 / 时刻表、站台长椅与垃圾桶。
- **电车**：两编组樱花色带近郊电车，循环「进站 → 停车开门 → 出站」；
  车头显示屏（普通 春野行）、前灯 / 尾灯、受电弓、转向架与车间风挡。
- **铁路**：双轨碎石道床、枕木、接缝亮斑、接触网与电力杆、轨旁信号机
  （随电车红绿切换）、站台端部警示围栏。
- **道口**：遮断机与电车联动（警报灯交替闪烁、栏杆降下）、X 警制标、
  「止まれ」路面标记、等待道口的女学生与自行车。
- **街道**：带缓曲线的沥青主街（白色边线、黄色中心虚线、斑马线）、
  路缘石、排水格栅、井盖；两侧电线杆（变压器 / 路灯 / 编号牌）与下垂电缆、
  进户分支线；便利店（橱窗货架 / 冷柜发光 / 春季海报）、咖啡店（遮阳棚 /
  黑板菜单 / 室外桌椅）、和菓子店（暖帘 / 纸灯笼 / 樱饼海报）、花店、书店、
  四栋日式住宅（瓦屋顶 / 晾晒衣物 / 空调外机 / 雨水管 / 围墙与绿篱）。
- **站前广场**：大樱花树、花坛、红邮筒、公共电话亭、巴士站牌、出租车候车牌、
  社区公告栏、地图牌、自行车停放区、扭蛋机。
- **自动贩卖机 ×5**：站台（背阴自发光）、站房两侧、便利店旁、安静街角。
- **自然**：17 棵樱花树（程序化树干 + 交叉面片花簇，带 alphatest 阴影）、
  灌木 / 草丛 / 地面花瓣堆积、远山薄雾、河堤、公告板云朵。
- **人物**：站员、看书乘客、道口女学生、贩卖机前的少年、购物的老人、
  咖啡店店员、放学的学生；墙头的猫、电线上的麻雀。

## 代码结构

```
index.html        入口与 UI（importmap 指向本地 three）
serve.mjs         极简静态服务器
js/cfg.js         布局常量与随机数
js/toon.js        三渲二核心：色阶 gradientMap / toon 材质 / 画布纹理 / 描边
js/ground.js      大地、道路（样条带状网格）、轨道、道床、广场
js/buildings.js   住宅与商店街
js/station.js     站房、站台、雨棚、站名标识
js/props.js       电线杆与电线、贩卖机、道口、长椅、小物
js/nature.js      樱花树、飘落花瓣（点精灵着色器）、植被、远山与云
js/train.js       电车与运行状态机
js/people.js      简约二次元人物
js/main.js        灯光 / 天空 / 雾 / 漫游控制 / 动画循环
```

所有材质使用 `MeshToonMaterial` + 4 级色阶 gradientMap；建筑以 `EdgesGeometry`
棱线勾边，电车与贩卖机用反向外壳描边；花瓣为自定义 `ShaderMaterial` 点精灵
（程序化花瓣形 + 旋转 + 风摆）。光影为 4096 阴影图的方向光 + 半球环境光，
阴影偏蓝紫，符合三渲二的柔和色阶。
