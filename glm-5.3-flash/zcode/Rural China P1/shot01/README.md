# 体素景观「客家土楼」— Fujian Hakka Tulou · Voxel Diorama

以纯程序化方式构建的**体素艺术(Voxel Art)客家土楼山地乡村微缩景观**。
不依赖任何建模软件:场景由 JavaScript 程序生成,并由自研软件渲染器输出等距视图;
同时导出 MagicaVoxel 标准格式的 `.vox` 模型文件,可直接打开编辑。

## 2. 建模逻辑

1. **离散体素唯一表达**:所有物体(建筑、地形、植物、道具)都落在同一张
   68×64×30 的体素网格上,一个体素 = 1 单位立方体,无任何平滑曲面或网格变形。
2. **确定性程序生成**:全部随机性来自整数坐标哈希(`hash3`)与值噪声
   (`fbm`),同一种子恒定复现;风化斑、苔藓、草地干湿、窗位缺失等
   "手工堆叠感"均由噪声场按体素独立决定。
3. **离散调色板着色**:约 40 种材质、共 106 个离散色,每种材质 2~5 个近似色,
   按坐标哈希取色形成颗粒抖动;不使用连续染色,保证 `.vox` 导出无损。
4. **形状由规则+扰动构成**:圆由"半径区间 + 每皮随机错动"生成
   (`r + (hash-0.5)*0.9 ∈ [12,15)`),因此墙面呈阶梯状体素圆并带夯筑的不规则感,
   而非算法完美圆柱。
5. **软件渲染**:暴露面剔除 → 顶点 AO(四阶) → 体素 DDA 日照阴影 →
   正交等距投影 → z-buffer 三角光栅化 → Lambert + 天空环境光 → 色调映射 →
   2×SSAA 降采样 → PNG(自带编码器,无外部库)。

## 7. 构建过程记录(2026-10-03)

### 7.1 环境探测与选型

- 环境探测:系统无 Blender、无可用的 Python(WindowsApps 为商店占位符),可用的运行时为 Node.js v26.4。
- 选型结论:采用**零依赖自研方案**——JavaScript 程序化体素建模 + 自研软件渲染器(正交等距光栅化),
  另导出 MagicaVoxel 标准的 `.vox` 与自包含 HTML 交互查看器,不调用任何外部建模/渲染软件。

### 7.2 实现里程碑

1. **体素核心库**(`voxel_core.js`):网格容器、确定性整数哈希 + 值噪声、离散调色板(约 40 材质 / 106 色)、建模分组。
2. **场景生成**(`scene_terrain / scene_tulou / scene_environment`):
   地形(岛屿剖面/道路放坡/池塘/水渠/梯田/菜园) → 土楼主体(夯土外墙/环形双坡瓦顶/木楼面/通柱环廊/
   分户隔墙与户门/木窗/双跑楼梯/凸出门脸主入口/天井与石井/内环祖堂) → 植被与乡村道具。
3. **渲染管线**(`render_core.js`):暴露面剔除 → 顶点 AO(四阶) → 体素 DDA 日照阴影 →
   正交等距投影 → z-buffer 三角光栅化 → Lambert + 天空环境光 → 色调映射 → 2×SSAA → PNG(自带编码器)。
4. **交付输出**:`main.js` 渲染三张成品图;`export_viewer.js` 打包网格二进制并注入模板生成 `tulou_viewer.html`。

### 7.3 调试与迭代记录

- **首轮渲染输出为稀疏点阵**,逐层定位并修复三个渲染器缺陷:
  1. 面角点坐标计算误用法向量的 x 分量(应按轴取 `n[a]`),导致 ±y/±z 面顶点全部坍缩;
  2. 三角形重心坐标公式符号错误(用了 `(P−B)×(C−B)`),几乎全部片元被剔除;
  3. 可增长数组 `push` 不支持多参数,`fCol.push(r,g,b)` 只写入 R 通道,颜色错乱。
- **视觉迭代(约 8 轮预览-检查-修改循环)**:
  墙体加高至 11 并重做夯土纹理(去横条带、细化风化斑);屋顶环重叠 0.2~0.3 消除抖动破洞;
  岛屿半径 30→27,建筑画面占比提升至约 55%;窗改为两层高并隔桶布置(避免连成带状);
  入口重建为凸出门脸 + 通高厚木门 + 檐下灯笼;相机仰角 36°→40°;阴影与 AO 适当加深。
- **交互查看器经真实浏览器实测**:WebGL 渲染正常,拖拽旋转、预设机位、按钮状态均验证通过。

## 8. 评测结果

- **评测结果:C**
- 交付物:见 §1 清单,全部位于本目录内(`tulou_viewer.html` / `tulou_scene.vox` / `renders/×3` / `src/` / 本 README)。
- 已知局限(自评,非评测方意见,供后续改进参考):
  1. 未产出 Blender 等标准 DCC 工程文件;对象层级以源码模块 + 体素分组表达,`.vox` 本身不含对象树;
  2. 渲染为自研光栅器输出,非行业 DCC/游戏引擎管线;
  3. 天井直径 16 体素,大于任务建议值 8~12(为强化俯视可读性的有意取舍);
  4. 无动画、多光源、夜景、人物动画等扩展加分项。
