# Pure Line Room — 冻结的接口与布局契约（所有模块必须遵守）

> 这是多 Agent 协作的唯一事实来源。任何模块都不得改动这里定义的坐标与 API。

## 0. 运行环境

- 纯浏览器、离线、经典 script（**不是** ES module）：不要用 `import` / `export` / `require`。
  所有文件通过 `<script src="js/xxx.js">` 按顺序加载，全局对象是 `window`。
- ES2019 语法即可（`Object.assign` 可用，可选链 `?.` 也可用）。
  禁止：外部 CDN、网络请求、图片、字体、音频文件。
- 每个模块都用 IIFE 包装：`(function (global) { 'use strict'; ... })(window);`
- 只使用 `PLR.*` 与 `M3.*` 提供的 API，不要 new 自己的渲染器。

## 1. 坐标与房间尺寸（米，Y 向上，原点在地板中心）

```
x: -1.70 (西墙/左)  …  +1.70 (东墙/右)
z: -2.60 (北墙/远)  …  +2.60 (南墙/近/相机背后)
y:  0.00 (地板)     …   2.72 (天花板)
```

- 默认相机在 (2.5, 1.42, 3.30) 附近，看向 (0, 1.15, -0.35)：**东墙(右)、北墙(远) 是主视面**。
- 东墙 x=+1.70 有窗洞：z ∈ [-1.36, -0.04]，y ∈ [1.03, 2.20]（窗台板已由 room.js 画出，y=1.03）。
- 西墙 x=-1.70 有门洞：z ∈ [0.86, 1.80]，高 2.06。
- 地板由 room.js 绘制：木板沿 x 方向分 6 列，接缝线在 x = -1.70, -1.1333, -0.5667, 0, 0.5667, 1.1333, 1.70；
  为躲避接缝，**贴地物件尽量把 x 落在 0.02 附近或成对偏移**。
- **y=0 就是地板面**。所有落地物件的底面必须是 y=0（或略高 0.001），不得穿地。

## 4. 视觉语言（决定成败，务必遵守）

**线条是主角**：每个面由「填充 + 描边」两部分组成。填充一律使用近白色材质键，靠面与面的边界线读出形体。

四种线宽等级（`PLR.K.*`，渲染器会自动按距离缩放）：

- `K.SIL` 2.35px — 只用于建筑级轮廓（墙、门框、大件家具的外轮廓）
- `K.EDGE` 1.35px — 家具结构线、面与面的交界（**默认**）
- `K.FINE` 0.95px — 内部构造线（抽屉缝、板缝、榫接、刻度、螺丝）
- `K.SOFT` 0.70px — 极淡的曲率提示线（圆柱的母线、抱枕的褶皱）

细节密度要求：**每件家具至少 12 个面**，主体家具（书桌/沙发/书柜/边柜）**至少 35 个面**，并且必须有：

1. 结构分件（桌面与桌腿分开、柜体与柜门分开、扶手与座面分开）；
2. 内部构造线（板材厚度、抽屉缝、门缝、螺丝/铰链、榫卯、木纹）；
3. 曲线物件（杯子、灯罩、地球仪、风扇、唱片）必须有母线/纬线/刻度类的淡线，否则会像塑料。

**材质键**（写到 `fill` 里，渲染时按昼夜自动换色，只能用这些）：

`@paper @wall @ceiling @floor @floorAlt @wood @woodDark @metal @metalDark @fabric @fabricAlt @rug @rugAlt @accent @plant @screen`

深色小面积（例如唱片、键盘黑键、花盆土）可以直接写十六进制颜色，例如 `'#2a2b33'`，但**禁止大面积纯黑**。

允许的额外面属性：`shade`（0…0.08，烘焙的轻微暗部）、`dot`（1 或 2，屏幕空间点阵）、
`hatch`（`{angle:45, gap:9, alpha:0.16}`，屏幕空间斜线阴影，用于地毯/阴影等）。

**禁止**：默认立方体拼装感（所有面等大等亮）、大面积纯黑、只有外轮廓没有结构线的简笔画。

## 5. 模块清单与注册契约

每个模块导出一个构建函数，由 `main.js` 按顺序调用：

```js
PLR.deskBuild    = function (sctx) { ... };   // js/desk.js
PLR.shelfBuild   = function (sctx) { ... };   // js/shelf.js
PLR.loungeBuild  = function (sctx) { ... };   // js/lounge.js
PLR.ceilingBuild = function (sctx) { ... };   // js/ceiling.js
```

`sctx`（由 main.js 构造）字段：

```js
sctx.scene      // PLR.Scene 实例：scene.addMesh() / scene.build(fn)
sctx.env        // { day, hour, minute, lightsOn, lampOn, … } 只读快照（会变，别缓存到闭包做判断）
sctx.parts      // {} 共享的命名对象表，把自己的 mesh 存进去便于调试
sctx.register   // register(object) 注册可交互物件（见 §6）
sctx.toast      // toast(text) 屏幕提示
sctx.WIN        // { z0, z1, y0, y1, x }  窗洞
sctx.ROOM       // { x0, x1, z0, z1, h }  房间内壁
```

## 6. 可交互物件的注册契约

```js
sctx.register({
  id: 'lamp',                       // 唯一 id
  label: '台灯 Desk lamp',           // 悬浮提示里显示的名字
  hint: '点击开关',                  // 悬浮提示里的操作提示（可选）
  mesh: lampMesh,                   // 用于悬浮描边加重的 mesh（必填）
  hit: { min: [x,y,z], max: [x,y,z] },   // 世界坐标 AABB（必填）
  priority: 2,                      // 同深度时的优先度（默认 0）
  onDown: function (ctx) {},        // 按下反馈（点击声等）
  onClick: function (ctx) {},       // 点击
  onDrag: function (ctx, info) {},  // 可选：拖拽（不要把拖拽和点击混在一起）
  update: function (dt, ctx) {},    // 每帧动画（dt 秒）
  dynamicHit: true                  // 若物件会大幅移动（如被拖拽），每帧重算 AABB
});
```

`ctx`（运行时回调参数）字段：

```js
ctx.env         // 活的环境对象（读；用 ctx.setEnv 改）
ctx.setEnv(patch)// 合并式修改环境，会触发全局重绘/重配音
ctx.audio.play(name, opts)  // 播放音效，name 见 §8
ctx.time        // 运行秒数
ctx.anim        // 动画/缓动工具（见 §7）
ctx.toast(text) // 屏幕提示
ctx.mesh        // = 注册时的 mesh
ctx.hover       // 是否正在 hover
```
