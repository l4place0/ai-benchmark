# Pure Line Room

一个**纯浏览器、完全离线**的互动线稿房间。整个房间是程序化生成的矢量线稿：
纸白色面片 + 墨黑描边，用画家算法做真实遮挡，所以它既是线稿，又有完整的空间感。

> 无后端、无网络、无 CDN、无外部字体、无外部图片、无外部音频。
> 所有几何、文字和声音都在运行时由代码生成。

---

## 一、启动方式

### 方式 A：直接打开（推荐，零依赖）

双击打开 `index.html` 即可。

`index.html` 通过一个**普通 `<script>`** 加载 `js/bundle.js`。
之所以不用 ES module 标签，是因为浏览器会因为 CORS 拒绝从 `file://` 加载 ES module；
打包成经典脚本后，直接双击也能跑。

### 方式 B：本地静态服务（可选）

任何静态服务器都可以，例如：

```
python -m http.server 8080
# 然后打开 http://127.0.0.1:8080/
```

服务器只负责发送文件，没有任何服务端逻辑。

### 重新打包（仅当你修改了 `js/` 下的模块源码）

```
node _dev/bundle.mjs
```

## 二、技术栈

| 部分 | 方案 |
|---|---|
| 渲染 | **自研画家算法线稿渲染器**，Canvas 2D（`js/core/renderer.js`） |
| 三维数学 | 自研 4×4 矩阵 / 相机 / 投影（`js/core/math3d.js`, `js/core/camera.js`） |
| 场景图 | 自研 Node / Part / Object 三层结构（`js/core/scene.js`） |
| 拾取 | **ID 缓冲**：离屏 canvas 用唯一颜色画每个可交互部件，读像素判断 hover/click |
| 音频 | **Web Audio API 纯合成**，无采样文件（`js/core/audio.js`） |
| 文字 | **自研单线矢量字体**（97 个字形），无字体文件（`js/core/strokefont.js`） |
| 打包 | 自研迷你打包器，ES module → 经典脚本（`_dev/bundle.mjs`） |
| 依赖 | **无**。没有 npm 包，没有构建工具，没有框架 |

> `js/bundle.js` 是 `_dev/bundle.mjs` 生成的打包产物（14 个模块），
> `index.html` 加载的是它。源码在 `js/` 里保持 ES module 结构，改完源码跑一次打包即可。
> 打包器还会校验每个 `import` 的具名导出是否真的存在，防止写错名字却静默变成 `undefined`。

### 渲染管线

1. 遍历场景图，把每个图元变换到相机空间（节点世界矩阵按"是否真的移动过"缓存）
2. 房间外壳做**背面剔除**——于是离相机最近的墙和天花板自动消失，形成剖面视角
3. 近平面裁剪 → 透视投影 → 按深度**从远到近排序**
4. 依次绘制：先填纸色（略向外膨胀以消除接缝），再描墨线，最后叠屏幕空间排线
5. 遮挡是第 4 步的副产品：近处的纸色面片自然盖住它后面的线

### 昼夜

`js/core/palette.js` 里有两套完整配色（Day / Night），运行时按 `nightT` 插值：
纸色、各类面片灰阶、墨色、强调色、天空、排线色一起过渡，同时音频环境层
（白天鸟鸣 ↔ 夜晚虫鸣）也跟着切换，灯光用径向渐变叠加（夜间用 `lighter` 混合）。

## 三、操作

| 操作 | 效果 |
|---|---|
| 拖动空白处 | 环绕房间旋转 |
| 滚轮 / `+` `-` | 推拉镜头 |
| 方向键 | 微调视角 |

## 四、已实现的可交互物件（69 个可拾取部件 / 23 个物件）

### 房间外壳（`js/content/room.js`）
- **门** —— 点击开合，合页摆动带弹性回弹；把手单独可交互，会转动
- **百叶帘** —— 16 片叶片错峰升降，每片有独立弹簧延迟，绳梯与拉绳跟着动
- **窗帘 ×2** —— 程序化褶皱，开合时褶皱幅度一起收敛
- **挂钟** —— 指针持续走**真实时间**（秒针连续扫动，不是每秒跳一格）；
  有 60 格刻度、48 齿滚花、12 个矢量数字；点击切换滴答声并让钟轻晃
- **装饰画 ×3** —— 点击在 3 幅程序化线稿之间交叉淡入淡出，画框有轻微回弹
- **灯光开关** —— 面板 + 可翘动的开关，切换全局昼夜
- **落地灯** —— 可开关，夜间灯罩发光并向房间投出光晕
- **插座 / 壁挂小盆栽 / 搁板上的书 / 衣帽钩** —— 各自的小反馈

### 书桌区（`js/content/desk.js`）
- **台灯** —— 摇杆开关（会翘动）、灯罩轻晃、灯泡亮起、灯下出现暖色排线光锥
- **杯子** —— 点击让三条互不相同的蒸汽带升起、卷曲、消散
- **椅子** —— 可拖动：带惯性滑行、脚轮滚动、松手后回弹并转正；单击原地转 180°
- **抽屉 ×2** —— 拉出 0.22 m，能看到抽屉盒和里面的纸/笔盘/小铁盒
- **柜门** —— 打开约 105°，撞到限位后弹一下；里面是隔板和纸盒
- **书 ×2** —— 抽出并倾斜
- **地球仪** —— 拖动自转 + 惯性衰减；点击给它一个自旋
- **笔筒** —— 点击让每支笔随机晃一下

### 客厅区（`js/content/lounge.js`）
- **唱片机** —— 播放/停止：唱盘从静止加速到 33⅓ rpm，唱臂从支架摆到唱片上，
  落下后开始音乐与黑胶底噪；唱片持续旋转
- **防尘盖** —— 掀开约 70°
- **书架上的书 ×4** —— 抽出/推回
- **书挡** —— 推动时整排书级联晃动
- **沙发坐垫** —— 压扁回弹（squash & stretch）
- **抱枕 ×3** —— 拍一下会蓬起来并换个角度落下
- **茶几** —— 可拖动，杯子里的水面会反向倾斜
- **地毯** —— 点击掀起一角再落下
- **海报** —— 卷边回弹，点击在两版构图之间切换
- **矮柜柜门** —— 打开可见一叠黑胶唱片

### 天花板（`js/content/ceiling.js`）
- **吊扇** —— 4 档（关/1/2/3），有升速与惯性滑行；高速时出现拖影叶片；
  叶片有真实倾角，下面挂着会摆的拉链
- **吊灯** —— 灯罩和拉线是两个独立交互；拉线会被拽下 36 mm 再弹回
- **风铃** —— 5 根铜管，始终有自然微风摆动（每根管子有相位差），
  点击后大幅摆动并按五声音阶错峰发声
- **悬挂装饰 ×2** —— 纸鹤串与星星螺旋，持续缓慢自转，点击给一个旋转冲量

## 六、声音

全部由 Web Audio 在运行时合成（振荡器 / 程序生成噪声缓冲 / 双二阶滤波 /
程序生成脉冲响应的卷积混响），**没有任何音频文件**。

- 16 种一次性音效：`click switch lampClick drawer cabinet doorOpen doorClose thud page
  chime globe ceramic cushion knock vinylDrop penClick`（每次播放的音高、音量、声像都有随机微差）
- 7 层持续音：`vinyl`（黑胶爆豆 + 底噪）、`music`（68 BPM 的 Dm9–Gm7–Cmaj9–Am7 循环，
  带贝斯与稀疏旋律）、`fan`（随档位变化的风声与电机声）、`day`（鸟鸣）、`night`（虫鸣）、
  `tick`（每秒滴答）、`rain`

浏览器要求首次用户手势才能出声，所以第一次点击/按键时才真正启动音频上下文。

### 实现备注（拾取）

拾取用离屏 ID 缓冲。Canvas 的路径填充一定带抗锯齿，所以**边缘像素是两种 id 的混色**，
会解码成毫不相干的第三个 id。这里做了两件事来消除它：

1. ID 通道的每个面片向内收缩成一个"实心核"——按质心向外膨胀约 1.2 像素，
   再用同色描边 2.2 像素，于是每个面片都完整覆盖自己的抗锯齿边缘；
2. 读取时取 3×3 邻域做多数表决，而不是读单个像素。

在这之前，一个 12×15 像素的小物件（杯子）旁边会有几百个虚假 id 像素，
导致 hover 命中错误的邻居。修好之后 34 个可定位部件里 33 个 hover 完全正确。
