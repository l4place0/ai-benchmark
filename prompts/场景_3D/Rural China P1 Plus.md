# AI Agent 3D 建模测试任务：体素景观「大型客家土楼村落」

## 1. 任务目标

目标任务目录：

`./Rural China P1 Plus/shot01/`

**严格限制：你只能读写目标任务目录内的文件。任何读写目标目录之外文件的操作都将视为测试 0 分（调用工具本身不受此限制）。**

请在目标目录下创建一个完整的、大型的 **Voxel Art（体素风格）客家山地村落景观场景**。

本任务不再是单体土楼建模，而是要求 AI Agent 理解并构建一个具有明确空间组织关系的：

> **大型福建客家土楼村落 / Hakka Tulou Village**

场景至少包含：

* **3 座可明确识别的土楼建筑**
* 多组客家传统民居建筑
* 村落道路系统
* 山地地形
* 植被系统
* 农田 / 菜园
* 水渠 / 小溪 / 水塘等自然或人工水系
* 村落公共空间
* 建筑之间具有合理的距离、朝向和层级关系

其中：

**至少一座为大型圆形土楼，至少另外两座土楼需要在形态、尺寸或空间组织上有所区别。**

场景不能表现为：

> “三座互不相关的土楼随机摆放在一块地形上”。

而应该表现为：

> **一个经过长期发展形成的、有道路连接、有公共空间、有民居、有农业生产区域、有自然环境的完整客家聚落。**

---

# 2. 核心场景目标

整个场景的第一视觉识别应当是：

**“福建山区中的大型客家土楼村落。”**

而不是：

* 三个圆形建筑
* 三个游戏建筑
* 一个中国风建筑群
* 普通乡村
* 普通古建筑群

场景需要体现：

### 聚落层级

**山地 → 村落 → 道路 → 建筑群 → 土楼 → 单体建筑细节**

### 建筑层级

**核心土楼 → 次级土楼 → 客家民居 → 公共建筑 → 农业及生活设施**

### 空间层级

**村落外围 → 村落道路 → 建筑群 → 土楼院落 → 中央天井**

整体视觉风格：

**低多边形 + Voxel + 手工堆叠感 + 东方乡土建筑美学 + 山地微缩景观**

不要制作成写实建筑渲染，也不要制作成简单的游戏方块地图。

---

# 3. 村落整体规模

建议将场景扩大到单体土楼的至少 **4～8 倍空间范围**。

推荐场景尺寸：

* 村落整体：约 100～160 个体素单位
* 地形高度：约 10～30 个体素单位
* 核心土楼：直径约 28～36
* 次级土楼：直径约 18～28
* 小型土楼 / 方楼：约 16～24
* 建筑之间保持明确间距
* 村落外围保留山坡、树林、农田等自然空间

不要让建筑全部挤在一起。

建筑之间应当形成：

**道路 → 空地 → 建筑 → 植被 → 农田 → 山坡**

这样的空间节奏。

---

# 4. 土楼建筑群

场景至少需要：

## 4.1 一号土楼：核心大型圆楼

这是整个村落的视觉主体。

建议：

* 圆形
* 三层或四层
* 外径约 28～36 个体素
* 高度约 12～16 个体素
* 厚重夯土墙
* 中央开放式天井
* 环形木质廊道
* 多层建筑结构
* 大型主入口

建议将其放置在村落中央或略偏中心的位置。

它应该是：

**全场最大的建筑。**

---

# 5. 二号土楼：中型圆楼

第二座土楼需要与核心土楼形成明显区别。

可以采用：

* 较小圆楼
* 两层或三层
* 更紧凑的内部院落
* 不同颜色的夯土墙
* 更简单的屋顶

建议尺寸：

* 外径：20～28
* 高度：8～12

它可以位于：

**核心土楼的一侧或村落道路附近。**

不要让第二座土楼与第一座完全复制。

应该体现：

**同一建筑传统下的不同建筑规模。**

---

# 6. 三号土楼：小型 / 异形土楼

第三座土楼必须具有一定差异。

可以选择：

### 方案 A：小型圆楼

直径约：

16～22

### 方案 B：椭圆土楼

呈略微拉长的环形。

### 方案 C：方形土楼 / 方楼

采用：

* 方形夯土外墙
* 中央庭院
* 多层结构
* 木质回廊

无论采用哪种方案，都必须让其明显属于：

**客家土楼建筑体系。**

不能只是普通方形民居。

---

# 7. 三座土楼之间的关系

这是本任务的重要测试内容。

三座土楼不应该只是：

```text
○     ○

    ○
```

随机排列。

应该建立明显的聚落空间关系。

例如：

```text
          山坡 / 森林
      🌲 🌲 🌲 🌲

            ○
        次级土楼

             │
          石板路
             │
       ┌─────┴─────┐
       │           │
      民居       小广场
       │           │
       └─────┬─────┘
             │
          大型圆楼
             ○
          /     \
       农田     水渠

             │
          小型土楼
             ○
```

建筑之间需要通过：

* 主道路
* 小路
* 台阶
* 小桥
* 广场
* 植被
* 农田

建立空间联系。

# 8. 客家民居建筑群

除至少三座土楼之外，还必须生成：

**一组具有客家风格的传统民居建筑群。**

建议数量：

**至少 8～15 栋。**

民居不要求全部独立建模到极高细节，但应具有明显的建筑语言。

可以包含：

* 单层民居
* 两层民居
* 坡屋顶建筑
* 小型砖木建筑
* 夯土建筑
* 木结构建筑
* 小型祠堂
* 村民公共建筑
* 仓房
* 厨房
* 杂物房

这些建筑不能都完全相同。

应当存在：

**大小变化、朝向变化、高度变化、屋顶变化。**

---

# 9. 客家建筑风格

民居需要体现：

* 厚墙
* 深色木门

# 10. 祠堂 / 公共建筑

村落中至少增加：

**1 个具有公共性质的重要建筑。**

推荐：

### 客家祠堂

可以采用：

* 对称布局
* 深色木门
* 灰瓦屋顶
* 石质台阶
* 小型广场

但需要在空间上具有：

**村落公共中心 / 精神中心**

的感觉。

# 11. 村落道路系统

道路不能只是装饰。

必须形成基本的：

**主路 + 次路 + 建筑入口道路**

系统。

建议：

### 主道路

宽约：

3～5 个体素。

连接：

**村口 → 核心土楼 → 主要建筑群**

### 次级道路

宽约：

2～3 个体素。

连接：

* 民居
* 小型土楼
* 农田
* 水井
* 公共建筑

### 小路

宽约：

1～2 个体素。

连接：

* 住宅
* 菜园
* 林地
* 水渠

道路应具有：

* 石板
* 泥土
* 不规则边缘
* 小型台阶

不要生成现代沥青路。

# 12. 村口

村落需要一个明确的：

**Entrance / Village Gate**

可以设计：

* 简单木门楼
* 石柱
* 小型牌楼
* 两侧树林
* 石板道路

村口应该成为整个场景的空间起点。

但不要制作成大型商业景区牌坊。

整体保持：

**朴素、乡土、功能性。**

---

# 13. 公共空间

村落至少需要一个：

**Village Plaza / Village Courtyard**

可以位于：

* 核心土楼附近

包含：

* 石板地面
* 水井
* 石桌
* 木凳
* 晒谷场

**有人生活，而不是建筑展示场。**

# 14. 农业景观

大型客家村落必须与农业生产环境产生联系。

至少加入：

### 菜园

* 小型蔬菜田
* 低矮篱笆
* 简单农具

### 农田

可以位于：

* 村落外围

* 梯田

# 15. 梯田

如果地形允许，应优先加入：

**山地梯田。**

要求：

* 顺应山坡高度
* 不要完全规则
* 具有明显台阶
* 每一级存在少量植被或农作物
* 使用泥土、石块和水体表达

梯田可以成为村落与山体之间的重要过渡。

---

# 16. 水系

村落至少加入一种水系：

* 小溪
* 水渠
* 水塘
* 小型池塘
* 灌溉渠

水系应当具有合理流向。

例如：

**山坡 → 小溪 → 村落水渠 → 农田**

或者：

**山泉 → 水塘 → 灌溉田地**

避免出现：

**没有来源、没有出口、随机切穿建筑的水体。**

---

# 17. 山地地形

场景必须明显处于：

**福建 / 中国东南山区环境。**

地形包括：

* 缓坡
* 小山丘
* 山谷
* 石坡
* 台地
* 梯田

不要制作成完全平坦的平面。

但也不要让山体完全遮挡建筑。

建议：

**村落位于一个相对平缓的山谷或山间盆地。**

外围逐渐升高。

# 24. 多土楼之间的视觉差异

三座土楼不能复制粘贴。

至少在以下项目中产生差异：

* 尺寸
* 高度
* 墙体颜色
* 屋顶形式
* 门窗数量
* 入口形式
* 内部庭院尺寸
* 建筑年代感
* 周边环境

例如：

### 一号土楼

大型、完整、保存较好。

### 二号土楼

中型、稍旧、周边植被较多。

### 三号土楼

小型、较低、局部风化明显。

这样才能形成：

**同一文化体系中的建筑多样性。**

# 25. 屋顶系统

所有主要建筑使用：

**传统中式灰瓦坡屋顶。**

包括：

* 土楼环形屋顶

**三层环形木质走廊。**

* 木梁

重点不是精确复制真实建筑，而是：

**让观察者能够清楚理解“围绕天井形成多层环形住宅结构”。**

---

# 28. 体素建模原则

这是整个测试的核心。

所有建筑与环境必须使用统一：

**Voxel Construction Language**

要求：

1. 使用离散体素结构。
2. 避免大面积平滑曲面。
3. 圆楼通过阶梯体素形成圆形。
4. 墙体通过体素堆叠形成。
5. 屋顶具有明显层叠。
6. 道路具有体素边缘。
7. 植物具有方块化结构。
8. 小物件也保持统一比例。
9. 允许少量人工误差。
10. 避免完全程序化的复制感。

---

# 29. 禁止的建模方式

禁止：

* 光滑圆柱体直接作为土楼
* 高精度 CAD 建模
* BIM 风格建筑
* 写实建筑模型
* 照片贴图
* 超复杂 PBR
* 现代游戏写实资产
* 高面数植物
* 光滑地形
* 大面积真实水面 shader

尤其禁止：

**用一个 Smooth Cylinder + Roof 就声称完成土楼。**

土楼的圆形必须能看出：

**由离散体素逐步构成。**

---

# 32. 村落空间组织

建筑布局应遵循：

**自然地形优先。**

不要将所有建筑排列成：

```text
□ □ □ □
□ □ □ □
□ □ □ □
```

应该具有：

* 错落
* 高差
* 朝向变化
* 建筑间距变化
* 道路连接
* 空地
* 院落
* 自然边界

建筑群应该看起来像：

**长期自然发展形成的传统村落。**

而不是现代规划住宅小区。

---

# 33. 色彩方案

整体保持：

**低饱和、自然、东方乡土色彩。**

主要颜色：

* 夯土：暖黄 / 土褐
* 木材：深棕
* 屋顶：灰黑 / 深灰
* 石材：灰白 / 灰色
* 道路：灰褐
* 植物：深绿 / 青绿
* 水体：低饱和蓝灰
* 天空：柔和蓝灰

不同土楼可以有轻微色彩变化。

但不能使用：

* 荧光色
* 霓虹色
* 高饱和游戏色
* 金属银色
* 科幻蓝光

---

# 34. 光照

采用：

**自然日光 + 柔和阴影。**

建议：

* 上午或下午
* 斜射光
* 柔和 AO
* 建筑产生明显体积阴影
* 天井内部略暗

## 45. 最终核心验收目标

最终场景应该能够回答以下问题：

**“如果把这个场景缩小成一张体素风格的村落模型，观者能否一眼理解这里是福建山区的客家土楼村落？”**

如果答案是肯定的，则说明场景基本达到了测试目标。

核心目标从原来的：

> **“做出一个土楼。”**

升级为：

> **“理解土楼是什么、理解土楼如何组成村落，并用统一的体素语言把建筑、道路、农业、山地和生活空间组织成一个完整的客家聚落。”**

### 测试任务核心关键词

**「至少三座土楼」 + 「客家建筑群」 + 「村落空间关系」 + 「山地环境」 + 「农业景观」 + 「道路水系」 + 「Voxel Diorama」**

这几个条件应当视为**硬性要求**，而不是可选增强项。
