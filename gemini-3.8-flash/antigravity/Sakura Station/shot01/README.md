# 🌸 三渲二樱花车站 (Sakura Station - 桜ヶ丘駅)
### 高度写意日系二次元动画风 Three.js 3D 漫游交互场景

> “秒速 5 厘米，那是樱花飘落的速度。”  
> 致敬新海诚（Makoto Shinkai）动画电影美学风格，融合京都动画（Kyoto Animation）生活化叙事质感。呈现春日下午四点柔和暖光、静谧铁道、摇曳电线与漫天飞舞的粉白落樱。

## 📸 场景核心特色

### 1. 精致“三渲二”（Cel-Shading）二次元美术风格
- **色阶阶梯着色（Toon Shading）：** 自定义 3 阶与 4 阶动画色阶光影过渡，消除写实材质的杂乱噪点。
- **动画感丁香灰紫投影：** 阴影区域呈现特有的淡紫/淡蓝反光色相调，避免死黑沉闷。
- **4:00 PM 斜射暖金阳光：** 侧后方 35° 斜射日光，拉长树影与建筑阴影，形成唯美斑驳感。
- **动画天空球与动态积雨云：** 渐变蔚蓝天顶向桃金地平线平滑过渡，柔和动画云朵缓缓漂移。

### 2. 完整铁道交通体系与通勤电车
- **近郊地面电车站（桜ヶ丘駅）：** 传统与现代结合的和洋折衷站房，包含駅名牌、检票闸机（IC 卡感应区）、切符自动售票机、壁挂时钟、春季樱花祭宣传海报与时刻表。
- **elevated 站台与雨棚：** 浅灰混凝土站台铺设黄色点状触觉盲道与白色安全界线，悬挂日式白底深蓝字駅名标（◀ みどり町 桜ヶ丘 花園 ▶）、长椅与站台自动贩卖机。
- **2 节编组近郊通勤电车（EMU）：** 
  - 经典珍珠白车体涂装，配以樱花粉（Sakura Pink）与薄荷绿（Mint Green）双色腰带。
  - 流线型动漫圆润车头、大曲面全景驾驶室车窗、暖黄高光前照灯与红宝石尾灯。
  - 细节车顶单臂受电弓（Pantograph）贴合架空接触网，车顶 AU75 不锈钢空调机组。
  - 逼真乘客车厢内部：立柱吊环、天蓝色沙发长椅与乘客剪影，车门支持交互式开启与关闭。
- **双轨铁路系统：** 银灰金属高光钢轨、深色枕木、道床碎石与缝隙间萌发的蒲公英野草，延伸至远方透视汇聚点的门型接触网立柱。
- **平交道口（踏切 - Fumikiri）：** 黑黄警示条纹遮断杆、交叉警示牌（踏切注意）、交互式红灯交替闪烁与地道叮咚警报铃音。

### 3. 日本近郊小镇街道与生活化建筑
- **蜿蜒起伏的主街道：** 微弯深灰沥青路面，印有白色“止まれ”停止标线、减速标记与斑马线，路边配有带金属格栅的水泥排水沟与堆积落樱。
- **传统和菓子店（さくら堂）：** 深木格栅推拉门、蓝染布质暖帘（印有樱饼与御菓子司）、檐下纸灯笼与室外野点红伞长椅。
- **日系便利店（SPRING MART 24H）：** 三色招牌灯箱、落地透光玻璃展示货架与冷饮柜、室外分类回收桶。
- **日式咖啡甜品馆（CAFE SAKURA）：** 墨红条纹布艺遮阳棚、手绘黑板立牌（樱花拿铁 🌸 ¥580）、室外散落花瓣的圆桌金属椅。
- **花店（Flower Garden）：** 浅绿遮阳棚下摆满木箱与锌铁水桶，盛开红黄紫粉郁金香、小雏菊与樱花枝。
- **典型独栋日式住宅：** 瓦片屋顶、雨水管、二楼阳台晾晒的白衬衫与校服、玄关表札（佐藤/田中）、陶瓷盆栽（紫阳花、矮松）。

### 4. 站前广场与标志性生活道具
- **站前大本命古樱树：** 树干盘屈舒展，树下围建八角形木质休息长凳，长凳上遗留有学生的书包与苏打水罐。
- **红色复古圆筒邮筒（〒）与深绿公用电话亭（NTT 电话机）。**
- **自行车停放区：** 停放带前置铁丝车篮的日式通勤“妈妈车”（Mamachari）。
- **4 台多色调自动贩卖机：** 红色 BOSS 咖啡、蓝色清凉饮料、白色天然矿泉水与粉色樱花限定款，配备微光饮品陈列窗与冷热标识。
- **电线杆与空中交错线路：** 附带变压器、绝缘瓷瓶、路灯与弧形自然垂坠的空中电缆，电线上驻足停留的小麻雀。
- **街角凸面反光镜、路边地藏石像（戴红围兜）与围墙上慵懒的小三花猫。**

### 5. 飘落樱花 GPU 粒子系统（2800+ 独立花瓣）
- **双叶微卷花瓣 3D 建模：** 呈现半透樱粉与高光质感。
- **风力涡流与螺旋翻滚动力学：** 模拟微风与横向气流，花瓣在空中翻滚、旋转与漫游下落。
- **“花吹雪”（Hanafubuki）暴风切换：** 一键开启强风暴雪式漫天落樱。
- **地面落樱堆积：** 墙角、路牙、排水沟与铁轨间自然聚积的粉色花瓣带。

### 6. Web Audio API 原生音效合成器
- **100% 本地即时合成，无外部音频文件依赖：**
  - 地道日本电车踏切双音叮咚警报铃声（784Hz / 698Hz 交替衰减）。
  - 春日微风呼啸环境白噪/粉噪带通滤波。
  - 日系车站发车提示旋律（E5-G#5-B5-E6 四音经典清脆钟声）。
  - 近郊通勤电车 AW-2 双音气笛声。

## 🚀 快速启动指南

### 方式一：Windows 一键双击运行（推荐）
在当前目录下，直接双击运行：
```cmd
start.bat
```
系统将自动启动内置高性能轻量 Web 服务器，并在默认浏览器中打开 `http://localhost:3000`。

### 方式二：Node.js 命令行启动
```bash
npm start
# 或者
node server.js
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000)。

### 方式三：静态服务器运行
您也可以使用任意静态 HTTP 服务器托管当前目录：
```bash
# Python
python -m http.server 3000

# 或 Npx serve
npx serve .
```

## 🎨 场景参数与技术指标

- **渲染引擎：** Three.js (r186.1)
- **色调映射：** ACESFilmicToneMapping (Exposure: 1.15)
- **色彩空间：** SRGBColorSpace
- **阴影技术：** PCFSoftShadowMap (2048x2048 Cascade)
- **目标帧率：** 60 FPS (PC 端流畅漫游)
- **依赖性：** 100% 零外部外链、免联网运行，所有纹理与几何体均为纯代码高精度即时生成。
