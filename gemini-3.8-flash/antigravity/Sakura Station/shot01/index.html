🌸 三渲二樱花车站 (Sakura Station)

基于 Three.js 打造的日系二次元“三渲二”樱花车站场景，致敬新海诚动画电影风格与日本近郊小镇慢生活风情。


🎮 交互操作指南：
  • 镜头导览 [1 - 5]： 点击或按数字键 1-5 快速切换经典电影级镜头（主街、站台、踏切、广场、俯瞰）。
  • 自由漫游 [R]： 进入第一人称行走视角，使用 WASD 漫游小镇街道、站台与广场，按住 Shift 可奔跑，鼠标左键拖拽旋转视线。
  • 自由环视 [O]： 进入轨道视角，鼠标左键旋转、滚轮缩放、右键平移。
  • 花吹雪： 切换风速，触发大量樱花花瓣在空中螺旋翻滚与漂移。
  • 电车控制： 点击车门开闭按钮伴随发车铃音，按 H 触发双音列车鸣笛。
  • 声音开关 [M]： 启用基于 Web Audio API 合成的地道日式踏切警报铃声、春日微风与车站提示音。
