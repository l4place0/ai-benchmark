# 🌸 桜ヶ丘駅 (Sakuragaoka Station) - 三渲二樱花车站 Three.js 场景

本项目依据“三渲二樱花车站”设计提示词规范进行全流程开发，构建了一个日系青春动画风格（新海诚/京都动画氛围）的 3D 樱花车站交互场景。

### 三、评测不合格原因剖析与复盘 (Root Cause Analysis)

尽管在功能覆盖度、场景元素完整度（20个章节全部具象化编码）以及交互性上做了全面实现，但本次评测结果为**不合格**，经技术复盘，主要存在以下深层次瓶颈与问题：

1. **纯代码程序化几何体（Procedural Primitives）的表现力天花板**
   - 场景全部采用 Three.js 基础几何图元（Box、Cylinder、Sphere、CatmullRomCurve3 等）在代码中拼装组合，未引入外部经过专业 3D 美术软件（Blender / Maya / 3ds Max）精细雕刻烘焙的高精度二次元 GLTF/GLB 工业级模型。
   - 模型的拓扑边缘、倒角弧度、复杂形体（如电车车头流线曲面、复古自行车机械结构、人物剪影、古树枝干树结）相较于手绘 3D 资产具有明显的机械感与体块感，难以达到商业级动漫电影（新海诚《秒速5厘米》、京都动画等）级别的细腻度。

2. **三渲二（NPR / Toon Shading）管线精细度欠缺**
   - 当前采用的 `MeshToonMaterial + Inverted Hull Outline` 属于较基础的三渲二技术方案。
   - 在复杂物体的面片交接处、细小构件（如栏杆、电线、窗框、电车扶手）上，顶点法线外扩描边容易产生线宽不均、断线、轮廓遮挡穿模或线框噪点。
   - 缺少基于深度（Depth Buffer）与法线缓冲（Normal Buffer）的屏幕空间边缘检测后处理（Screen Space Edge Detection Post-process Pass），以及定制化色阶阈值控制器。

3. **贴图与手绘材质细节层次不足**
   - 依赖 Canvas 动态绘制的文字标牌与纹理虽然保证了零网络静态资产依赖，但缺乏专业二次元手绘纹理（Hand-painted Textures）的高光渐变、水彩笔触质感、风化磨损细节和法线贴图（Normal Map）细节，整体画面扁平感较强。

4. **光影后处理与氛围氛围渲染深度有限**
   - 未接入完整的后期辉光（UnrealBloomPass）、色调映射 LUT（Color Grading LUT）、镜头暗角（Vignette）、轻微色散（Chromatic Aberration）及体积光（God Rays / Sun Shafts）复合后处理流水线，导致春日下午 4 点的“空气通透感与泛光微尘感”未能达到震撼的视觉冲击力。

## 🌟 核心特色与系统实现清单

### 1. 三渲二（Cel-Shading）核心视觉管线
- **阶梯式离散光阶（Stepped Anime Shading）：** 使用经过专门校准的 3-Step 动画色阶映射表（`materials.js`），受光面明亮通透，背光阴影呈现具有二次元动画电影质感的淡紫蓝/薰衣草灰色调（非写实脏黑死黑）。
- **反转外壳描边系统（Inverted Hull Anime Outlines）：** 对车站、电车、建筑、电线杆与道具进行模型法线外扩墨线渲染，呈现干净克制的手绘动画线稿轮廓。
- **软质动漫树冠法线平滑：** 针对樱花树团块采用自中心向外发散的球面法线重计算技术，消除机械棱角，形成吉卜力与新海诚式的蓬松棉云状粉白树冠。

### 2. 空间布局与丰富建筑群
- **主街纵深：** 微弧度弯曲缓坡主街，铺设略褪色深灰沥青、修补色块、清晰白色路边线、橙黄中心线，以及「**止まれ**」（停步停让）、减速「**30**」和行人优先斑马线。
- **两侧商店街与住宅群：**
  - **和菓子店「さくら堂」：** 传统木造昭和建筑、深木框推拉门、浅粉布质暖帘（印有「和菓子 さくら堂」）、门前红色长椅与樱花麻薯展示。
  - **便利店「DAILY POP」：** 现代白色外墙、标志性橙绿蓝三色横向招牌、通透落地玻璃、发光货架与冷饮柜、轮椅无障碍斜坡与黄色盲道导引砖。
  - **咖啡馆「CAFE CERISIER」：** 奶油灰泥搭配深棕木框、复古墨绿布艺遮阳棚、手写黑板立式菜单（「桜カフェラテ ¥550」、「苺のショートケーキ」）、户外圆桌金属椅与桌面积樱花瓣。
  - **花店「花日和」：** 嫩绿拼米白外立面、门前层叠木架、装满郁金香、满天星与樱花枝的镀锌铁桶、价格手写标牌。
  - **独栋住宅群：** 双层坡屋顶独栋住宅，二楼晒衣阳台晾晒随风轻拂的白色衬衫与毛巾、一楼玄关门牌、绣球花盆栽、外挂空调室外机与屋顶八木电视天线。

### 3. 铁道系统与 1000 系电车
- **双轨铁道：** 碎石道床、防腐深棕木质枕木、顶部锃亮银灰/侧面氧化锈迹的金属钢轨。
- **架空接触网（Catenary）：** 高耸钢构电力立柱、横梁、悬挂瓷绝缘子、承力索与接触导线，在远景产生强烈的透视汇聚感。

- **环境生机痕迹：** 围墙上方蜷缩打盹的三花猫、电线上伫立的麻雀、街角橙色交通反光凸面镜、红色「消火器」灭火箱、路边橘色交通锥、花坛盛开的郁金香与雏菊。

### 5. 动态 3D 落樱粒子与环境音效
- **2,400+ 片 3D 受风落樱系统：** 真实心形凹口樱花瓣贴图，随春风呈现三维翻滚、横向漂移、扰流旋转与重力缓降，落在屋顶、月台遮雨棚、电车顶与道路角落。
- **合成声景（Web Audio API）：** 纯代码程序化合成春日轻柔微风、经典真实 700Hz/750Hz 双频交替道口警报钟声（「カンカンカン...」）、电车轻微低频怠速共鸣与枝头雀鸣，零外部音频资源依赖，即开即播。

## 🚀 启动与体验方法

由于场景使用了现代 ES Modules（ECMAScript 模块），建议通过任意本地静态 Web 服务器运行：

### 方式一：Node.js
在工作目录 `Sakura Station/shot02` 下运行：
```bash
npx serve -l 3000
```
或
```bash
npx http-server -p 3000
```

### 方式二：Python
```bash
python -m http.server 3000
```

启动后在浏览器打开：
`http://localhost:3000`
