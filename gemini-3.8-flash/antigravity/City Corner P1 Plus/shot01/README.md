# 雨夜便利店街角微缩模型 (City Corner P1 Plus - Shot 01)

## 1. 项目概述
- **评级结果**：C
- **项目定位**：日系二次元动画风“雨夜便利店街角”微缩 3D 景观模型（Diorama），第三视角自由旋转、缩放与平移，纯净无 UI 界面。
- **技术栈**：HTML5 + WebGL (Three.js r128 本地离线引擎) + OrbitControls。

---

## 2. 迭代过程与问题复盘

| 阶段 | 核心工作 | 暴露问题与根因 | 修正方案 |
| :--- | :--- | :--- | :--- |
| **初始搭建** | 完成微缩底座、便利店建筑、通透大玻璃、极其充实的便利店内部陈列、街角外部道具及全套雨夜动效系统 | 底座上未见斑马线与路面标线；雨丝过白过粗影响观感 | 下调雨丝粗细与透明度；重构路面贴图生成器 |

## 3. 最终功能与实现特性

- **视觉风格**：
  - 纯正三渲二（MeshToonMaterial + Cel-Shading Ramp 分级阶梯）材质。
  - EdgesGeometry 手绘动漫墨线勾边。
  - 冷调湿润雨夜 vs 便利店内部暖金光晕强烈对比。
- **便利店主体与陈设**：
  - HOTARU MART 发光大招牌、挑檐雨棚筒灯、落地大窗、自动感应双移门。
  - 内部陈设：发光冷饮柜、双排零食货架、便当饭团中岛、双屏 POS 收银台、现磨咖啡机、微波炉、杂志架、雪糕冰柜、关东煮柜台与白汽粒子。
- **街角外部元素**：
  - 双色自动贩卖机、空罐回收箱、经典 Mamachari 自行车、雨伞架与透明伞、分类垃圾桶。
  - 街角复古路灯、水泥电线杆、变压器与悬垂电线网、过街信号灯、停止指示牌。
  - 排水沟铸铁格栅、黄色防撞护栏柱、深邃侧巷周转箱与空调外机。
- **路面与交通标线**：
  - 双向规范日式横断步道（平行行车方向的白色矩形条带，标准 45cm 间距与宽度）。
  - 双向车道停止线与行人过街预告菱形标线（◇）。
  - 规范迎面“とまれ”日语道路粗体标字。
  - 湿润沥青纹理与自然微反光水洼。
- **动态系统**：
  - 细密倾斜雨丝持续下落。
  - 地面积水涟漪同心圆扩散。
  - 屋檐规律水滴与玻璃表面雨流滑动。
  - 自动门感应平移开合、信号灯红绿交替与招牌微颤。
