# 大型客家土楼村落 (Hakka Tulou Village Diorama) - 3D 体素建模技术说明

## 1. 项目概况与设计理念

本项目基于真实福建客家山地聚落的空间组织逻辑，在目标目录 `./Rural China P1 Plus/shot01/` 中完整构建了一个大型 **Voxel Art（体素风格）客家聚落微缩景观**。

场景摒弃了“孤立建筑展示”或“平铺模型拼凑”的思路，完整再现了客家聚落长期历史发展形成的紧密依存关系：
$$\text{山水脉络} \longrightarrow \text{道路骨架} \longrightarrow \text{公共礼序轴线} \longrightarrow \text{核心土楼堡垒} \longrightarrow \text{民居集群} \longrightarrow \text{梯田农业}$$

所有建筑、地形、植被与生活设施均严格采用**离散体素构建语言（Discrete Voxel Art）**，杜绝任何平滑曲面与现代工业元素，形成极具手工堆叠感、东方乡土美学与生活温度的微缩山地聚落。

## 3. 客家民居群与公共建筑体系

村落严格按照功能与地形肌理组织了 **1 栋核心公共宗祠 + 13 栋客家传统民居**：

1. **客家宗祠 (Ancestral Hall)**：
   - 坐标 $(78, 50)$，位于主广场南侧，与一号大圆楼共同确立全村南北礼序精神主轴。
   - 采用传统三开间一进对称合院，正脊设有典型客家**燕尾脊（翘角）**，大门前立有一对石鼓（门当户对）与迎门灯笼。
2. **西北半坡民居组团 (Cluster A, 3栋)**：
   - 双层带院落农宅 $(26, 88)$、坡顶石基民房 $(44, 88)$、抬高防潮木仓房 $(60, 104)$。
3. **中央广场生活民居组团 (Cluster B, 4栋)**：
   - 宗祠西侧传统客家民居 $(58, 48)$、东侧合院民宅 $(98, 48)$、广场西侧两层茶楼走廊 $(60, 64)$、工匠手工作坊 $(96, 64)$。
4. **东侧溪畔民居组团 (Cluster C, 3栋)**：
   - 依山就势的双层大宅 $(138, 90)$、亲水溪畔农居 $(118, 98)$、水磨坊农舍 $(138, 44)$。
5. **南部农业生产用房组团 (Cluster D, 3栋)**：
   - 制茶晾晒作坊 $(46, 34)$、樵夫储柴仓 $(102, 32)$、带敞棚粮仓与畜棚 $(124, 26)$。

## 4. 道路与水系组织系统

1. **道路层级**：
   - **主干石板路（宽 3~4 体素）**：自村口牌坊 $(32, 16)$ 出发，穿过水田菜园边缘，进入村落中央大广场 $(78, 62)$，直通一号土楼南大门。
   - **次级道路（宽 2~3 体素）**：自广场向西北延伸石阶通达二号圆楼；向东横跨石板拱桥 $(115, 90)$ 通达三号方楼与东侧民居。
   - **生产小径（宽 1~2 体素）**：鹅卵石与夯土小路蜿蜒穿入梯田、竹林与菜园。
2. **村口门楼 (Village Gate)**：
   - 位于西南山坳处 $(32, 16)$，设有质朴的木石牌坊门楼、红灯笼、村界石碑，两侧矗立两株冠幅庞大的双生古榕树。
3. **自然与人工水系**：
   - **东北高山溪流 (Mountain Brook)**：发源自东北山峰 $(150, 150)$，沿石滩阶梯跌水下泻，穿过石桥贯穿村落东侧。
   - **半月形风水塘 (Fengshui Pond)**：位于宗祠正前方 $(78, 26)$，石砌弧形池壁，塘中浮萍荷叶，设有石阶埠头供村民汲水洗涤。
   - **农田灌溉水渠**：引山溪与池水环绕流入西南梯田水网。

## 5. 农业生产、生态植被与生活设施

1. **立体山地农业**：
   - **水稻梯田 (Terraced Rice Paddies)**：顺应山势分为4级阶梯台地，田埂由毛石垒砌，田内蓄水平整，点缀嫩绿稻苗。
   - **等高线茶园 (Tea Plantation)**：阶梯缓坡上规整种植圆形体素茶树树丛。
   - **蔬菜菜园 (Vegetable Gardens)**：垄沟清晰的菜畦、低矮木栅栏、农具架。
2. **植被系统**：
   - **三大竹林组团**：西北土楼后山背风竹林（40株）、东北溪谷竹林（32株）、西界山林竹林（26株），采用节状竹竿与伞状体素冠层。
   - **常青黄山松林**：盘踞于北侧高山山脊，层叠针叶枝桠。
   - **民居果树**：点缀金黄成熟柿子果实的柿子树。
3. **客家生活细节与人物尺度**：
   - 广场石井（附木辘轳）、石桌石凳、竹席晒谷场（铺满金黄稻谷）、整齐堆叠的木柴垛、陶制大水缸。
   - 6 名客家村民：挑担穿行、田间耕作、广场晒谷、大门闲谈、过桥劳作；水田旁卧有水牛，院落中散养公鸡母鸡。

### 6.2 3D 检视与浏览方式
1. **直接双击打开 `index.html`**：
   - 已内置完全离线的本地 Three.js、OrbitControls、GLTFLoader 与 Base64 模型数据，**无需网络、无需外部服务器，完全解除浏览器 `file:///` 协议的跨域限制**，双击即可直接在浏览器内 360° 旋转游览。
2. **通过本地微服务打开（推荐）**：
   - 直接双击当前目录下的 `start_viewer.bat`，将自动启动本地极速 HTTP 服务并在默认浏览器打开 `http://localhost:8080/index.html`。
3. **在 3D 建模软件中打开**：
   - 可将 `tulou_village.glb` 或 `tulou_village.obj` 直接拖入 Blender、Maya、3ds Max、Unity 或 Unreal Engine 中。
   - 可将 `tulou_village.vox` 直接用 MagicaVoxel 打开。

## 7. 测试评估与过程复盘 (Evaluation & Retrospective)

### 7.1 测试评分
- **最终评级**：`A-`
- **扣分原因**：交付过程中出现两次交互与坐标配置的小错误（均已即时定位并彻底修复）。

### 7.2 问题复盘与解决过程
1. **问题一：本地 `file:///` 协议跨域拦截导致 3D 网页加载停滞**
   - **现象**：用户直接双击打开 `index.html` 时页面停留在加载动画。
   - **根因**：现代浏览器同源策略阻止 `file:///` 协议下异步请求外部 `.glb` 模型，且外部 CDN 脚本存在网络访问延迟。
   - **修复**：将 Three.js 相关核心脚本全部转为本地文件存储；将 3D 模型数据编码为 Base64 内嵌于 `model_data.js` 中，通过内存同步解析完全规避跨域拦截，并附带 `start_viewer.bat` 本地微服务备用入口。
2. **问题二：WebGL 视图坐标系朝向未转换导致模型侧立（斜置）**
   - **现象**：网页载入后模型垂直立起，视角正对切面底板。
   - **根因**：体素生成算法使用 $Z$ 轴作为高度方向（$Z$-Up），而 Three.js 默认世界坐标系为 $Y$ 轴朝上（$Y$-Up）。
   - **修复**：在导出阶段对 OBJ 与 GLB 顶点了实施纯旋转映射（$X'=x-80, Y'=z, Z'=80-y$），将村落地面平整对齐至水平 $XZ$ 平面，并重新校准正交轴测与各视角预设摄影机参数。

### 7.3 最终交付结果
- **3D 资产**：`tulou_village.glb`、`tulou_village.obj`、`tulou_village.mtl`、`tulou_village.vox` 格式齐全，体素结构规范、法线正确。
- **渲染成果**：4 张 1920×1080 视角渲染图（主轴测、透视航拍、大圆楼特写、聚落空间关系）全部就绪。
- **交互验证**：`index.html` 离线双击即可流畅进行 360° 全方位交互检视。
